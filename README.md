## Descripción del caso
La comunidad educativa necesita una plataforma informal que mejore la comunicación entre
estudiantes. La Red Social Pascualina permite crear perfiles con intereses y habilidades,
seguir a compañeros (incluida la mentoría entre pares), publicar actualizaciones, comentar
y reaccionar, crear y unirse a grupos de estudio o clubes, y programar eventos.

Este repositorio contiene el diseño de su base de datos, organizado por tareas.
